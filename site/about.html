AI security · Model Context Protocol

Every request earns its answer. Or leaves a record of why it didn't.

An MCP tool server for regulated environments. Agents reach retrieval tools only over mutual TLS with scoped tokens, answers must cite their sources, and nothing leaves the network.

    End-to-end tests start the real server over HTTPS and talk to it with the real MCP client. There are no mocks at the transport layer.

    Run it yourself.

    python scripts/gen_certs.py --out certs      # throwaway CA, server and client certs
python run_server.py                         # https://localhost:8443/mcp, client cert required
python -m agents.orchestrator "How do workloads reach KMS without internet egress?"

    Hosting this publicly would mean terminating TLS somewhere other than the server, which removes the point of mutual TLS. That is why this page replays recorded sessions instead.
